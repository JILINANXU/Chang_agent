畅Agent 使用说明

一个跑在你自己电脑上的编码智能体：你用中文描述要改什么，它自己读文件、改代码，并把每一步都摊开给你看。 全部文件操作都限制在你指定的工作区里，改动前先备份。

1. 它是什么

畅Agent 不是聊天机器人，而是一个「会动文件」的执行器。它的工作循环是：

  1. 思考 —— 根据你的需求决定下一步做什么；
  2. 调用工具 —— 列目录、读文件、搜索、改文件；
  3. 观察结果 —— 看到工具返回后继续下一步，直到任务完成；
  4. 汇报 —— 给出最终答复，并列出改过哪些文件。

整个过程通过 SSE 实时推送到页面，所以你能看到它「正在做什么」，而不是干等一个结果。

2. 快速开始

在项目根目录执行一条命令：

python run.py

它会自动完成四件事：检查 Python 版本、补齐缺失依赖、读取配置、启动服务并打开浏览器（默认 http://127.0.0.1:8765，端口被占用会自动顺延）。

常用参数：

命令作用
python run.py --port 9000指定端口
python run.py --no-browser只起服务，不开浏览器
python run.py --reload开发模式：改代码自动重启
python -m changagent --check命令行查看当前配置与工具清单（不调用模型）

3. 两种模式

顶栏右上角的徽章会告诉你当前处于哪种模式：

演示模式 灰色

播放一段预置的完整工作流，用来熟悉界面。不调用任何模型，不消耗额度，也不改动文件。

适用于：第一次打开、给别人演示、排查界面问题。

真实模式 绿色

接入真实模型，事件来自 Agent 内核，会真实读写工作区里的文件。

适用于：真正干活。

切换方式是在项目根的 .env 里设置：

CHANG_AGENT_WEB_MODE=live
CHANG_AGENT_API_KEY=你的密钥
CHANG_AGENT_BASE_URL=https://api.agnes-ai.cn/v1
CHANG_AGENT_MODEL=agnes-2.5-flash

真实模式的两个前提是 有 API Key 且 装了 openai 库； 任一不满足，启动口会自动退回演示模式并在终端说明原因，不会白屏报错。

4. 界面导览

区域内容
顶栏工作区路径、当前模型、模式徽章、重置按钮
左栏工作区文件树（只读展示）、示例任务（点击即填入输入框）
中栏对话流：你的需求 → 思考 → 工具卡片 → 文件改动 → 最终答复；底部是输入区
右栏文件变更列表（含逐行 diff）、本次运行统计（状态 / 步数 / 工具调用 / 耗时）

几个好用的细节：

  • Ctrl + Enter 运行；运行中输入框仍可编辑，按钮会变成「停止」；
  • 工具卡片点标题栏可折叠，结果超过 28 行会自动收起；
  • 对话流智能滚动：你手动往上翻之后，它不会再强行拽到底部；
  • 窗口变窄时右栏、左栏会依次收起，diff 在对话流里依然可见。

5. 它能做什么

Agent 的能力边界就是下面这些工具，每个工具只做一件原子的事：

工具作用是否改动文件
read_file读取文本文件（带行号，支持分段读）否
list_dir查看目录结构否
glob_search按文件名模式找文件，例如 **/*.py否
grep_search按内容搜索，返回「文件:行号: 内容」否
edit_file对已有文件做精确片段替换（推荐，不会误伤没让动的地方）是
write_file新建文件，或整体覆盖是
run_command执行命令（默认关闭，需显式开启）视命令而定

改文件前有一道硬约束：必须先读过原文件。所以「没读就改」会被直接拒绝， 这是为了防止模型凭猜测改坏代码。

6. 安全边界与回滚

三道闸

  1. 路径沙箱：所有路径都解析成绝对路径后校验，必须在工作区之内。 用 ../ 或写绝对路径想溜出去，会被直接拒绝并记一次违规。
  2. 敏感文件拦截：.env、.git/、*.pem、*.key、 .changagent/ 等一律不可读不可写。
  3. 写前备份：任何覆盖或修改前，原文件都会先复制一份。

改动怎么回滚

每次写操作都会在运行目录留下原文件副本，目录结构是：

<工作区>/.changagent/backups/<时间戳>/<原文件相对路径>

回滚就是把备份复制回原位。例如在 PowerShell 里：

# 先看看有哪些时间点
Get-ChildItem .changagent\backups

# 把某个时间点的备份整体还原（示例时间戳）
Copy-Item .changagent\backups\20260918-143055\* . -Recurse -Force

关于人工确认

命令行模式下，每次写文件前会先展示改动内容并询问是否继续。而网页是单向事件流，无法暂停等你点确认， 所以真实模式需要设置：

CHANG_AGENT_AUTO_APPROVE=true

这个开关的含义是：你点击「运行」就等于授权本次改动。 它不会跳过沙箱和备份，但不会逐次问你。如果你的任务涉及重要文件，建议先备份整个目录，或改用命令行逐次确认。

7. 配置项一览

全部写在项目根的 .env 里（可从 .env.example 复制）。 优先级：环境变量 > .env > 代码默认值。

变量默认值说明
CHANG_AGENT_API_KEY空模型密钥，必填（真实模式）
CHANG_AGENT_BASE_URLhttps://api.deepseek.com/v1任意 OpenAI 兼容端点
CHANG_AGENT_MODELdeepseek-chat模型名，必须支持 Function Calling
CHANG_AGENT_TEMPERATURE0编码任务建议 0，保证稳定
CHANG_AGENT_TIMEOUT120单次模型请求超时（秒）
CHANG_AGENT_MAX_RETRIES3失败重试次数（指数退避）
CHANG_AGENT_WORKSPACEexamples/demo_workspace工作区（沙箱根目录）
CHANG_AGENT_MAX_STEPS25单任务最大步数，防无限循环
CHANG_AGENT_TOKEN_BUDGET32000上下文预算，超出自动压缩
CHANG_AGENT_ENABLE_SHELLfalse是否提供 run_command
CHANG_AGENT_AUTO_APPROVEfalse是否跳过逐次写入确认
CHANG_AGENT_BACKUPtrue写入前是否备份
CHANG_AGENT_WEB_MODEdemodemo 或 live

8. 常见问题

点了运行没反应，或者提示"未配置 API Key"

检查是否把 .env.example 复制成了 .env（模板文件本身不会被读取）， 以及 CHANG_AGENT_API_KEY 是否填了真实值。

提示 401 / 404

401 是密钥无效或过期；404 通常是模型名或 Base URL 写错了。 错误信息里会带上当前使用的模型名和端点，对照配置改即可。

提示 429

触发限流或额度不足。稍等重试，或换个模型。

页面左侧文件树是空的

工作区目录不存在，或里面确实没有文件。检查 CHANG_AGENT_WORKSPACE 指向的路径。 注意以 . 开头的文件和依赖目录（node_modules、.venv 等）不会被展示。

Agent 卡住不动了

单步默认最多等 120 秒，超时会自动重试再报错。如果长时间没动静，可以直接点「停止」。

同一个工具连续失败三次就中断了

这是内置的熔断保护，避免模型反复用错工具空烧额度。 通常说明目标文件不存在、路径写错了。检查工作区状态后重新下指令即可。

端口被占用

启动口会自动顺延到下一个可用端口，并在终端告诉你实际端口。

9. 目录与产物

畅agent/
├─ run.py                  启动口（一条命令起服务）
├─ .env                    你的配置（已被 .gitignore 忽略）
├─ .env.example            配置模板
├─ docs/                   设计、工具、提示词、Web 四份文档
├─ changagent/
│  ├─ config.py            配置解析
│  ├─ cli.py               命令行入口
│  ├─ llm/                 模型客户端与消息结构
│  ├─ tools/               工具实现与注册表
│  ├─ core/                主循环、沙箱、上下文压缩、会话记录
│  ├─ prompts/             system / tool_guide 提示词
│  ├─ ui/                  终端渲染
│  └─ web/                 服务端与静态页面
└─ examples/demo_workspace 默认演示工作区

运行后在工作区里会多出一个运行目录：

<工作区>/.changagent/
├─ sessions/<时间戳>-<id>.json   完整会话记录（任务、每步工具调用、结果）
├─ backups/<时间戳>/<相对路径>   写入前的原文件备份
└─ state.json                    最近一次会话的指针

这些文件是纯文本 JSON，可以直接翻看 Agent 到底做了哪些操作、每一步花了多久。
